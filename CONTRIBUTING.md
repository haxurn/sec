# Contributing to Cybersecurity Learning

Thank you for your interest in contributing!

## How to Contribute

### Reporting Issues

- Use the [Issue Tracker](https://github.com/haxurn/sec/issues) to report bugs or request features
- Check if the issue already exists before creating a new one
- Include detailed steps to reproduce the issue
- For security vulnerabilities, please see Security Policy below

### Pull Requests

1. **Fork** the repository
2. **Create** a feature branch: `git checkout -b feature/your-feature`
3. **Commit** your changes: `git commit -m 'Add some feature'`
4. **Push** to the branch: `git push origin feature/your-feature`
5. **Submit** a Pull Request

### Code Guidelines

- Follow existing code style and conventions
- Add comments for complex logic
- Update documentation for any changes
- Test your changes before submitting

### Content Guidelines

- All content must be for **educational purposes only**
- Do not include real exploit code targeting specific systems
- Provide proper attribution for referenced materials
- Ensure content is accurate and up-to-date

## Topics Welcome

- Web application security
- Network security
- Penetration testing guides
- Secure coding practices
- Security tools and scripts
- Vulnerability write-ups (with proper disclosure)

## Security Policy

For security vulnerabilities, please **do not** create a public issue. Instead, contact the maintainer directly.
