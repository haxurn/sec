# Security Policy

## Supported Versions

Currently supported versions of this project:

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do **NOT** create a public issue.

Instead, please contact the maintainer directly:

- **Email**: Available on GitHub profile
- **Private Security Report**: Use GitHub's private vulnerability reporting

Please include:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Any suggested fixes (optional)

## Scope

This security policy applies to:

- All code in this repository
- Documentation and learning materials
- Any associated web services (if applicable)

## Out of Scope

- Vulnerabilities in third-party dependencies (please report to respective maintainers)
- Social engineering attacks
- Physical security
- Denial of service attacks on third-party services

---

**Educational Use Only**: This repository contains materials for cybersecurity education. Always obtain proper authorization before testing systems you don't own.
